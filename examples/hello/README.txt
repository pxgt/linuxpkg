hello
=====

An example package built with linuxpkg. It installs:

  /usr/bin/hello                    the program (a shell script)
  /usr/bin/hi                       a symbolic link to hello
  /etc/hello.conf                   a configuration file
  /var/lib/hello/                   a directory
  /usr/share/doc/hello/README.txt   this file

Run `hello` to see it work.
